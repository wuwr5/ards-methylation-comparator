# Comparator dependence of blood DNA methylation biomarkers for ARDS

Re-analysis code for the manuscript *"Comparator dependence of blood DNA methylation
biomarkers for ARDS: a re-evaluation"*.

In 2019, Zhang et al. reported a four-CpG whole-blood DNA methylation signature
(cg03341377, cg24310395, cg07830557, cg08418670) that appeared to diagnose ARDS with
near-perfect discrimination (single-CpG AUC up to 0.99). Critically, their original
dataset (GSE67530) also contained **75 non-ARDS ICU controls** that were never used
when building the signature — only healthy participants served as comparators.

This repository re-analyses GSE67530 with a three-contrast design that puts those
idle ICU controls back into the analysis:

| Contrast | Role | Key result |
|---|---|---|
| ARDS vs healthy (39 vs 30) | Replication | 131,444 DMPs (FDR < 0.05); 4-CpG AUC 0.976–0.997 |
| ICU control vs healthy (75 vs 30) | Critical-illness effect | 142,254 DMPs — signal of the same magnitude |
| **ARDS vs ICU control (39 vs 75)** | ARDS-specific signal | **0 DMPs; 4-CpG AUC 0.561 (95% CI 0.448–0.675)** |

Mechanistically, estimated neutrophil fractions are 87.33% (ARDS) vs 87.34% (ICU
controls) vs 65.4% (healthy), and adjustment for blood cell composition attenuates
the case-vs-healthy signals by 99.97%/99.6% (six-fraction model) or 91.3%/92.4%
(neutrophil-only sensitivity analysis). The same direction of bias replicates in an
independent COVID-19 cohort (GSE199591, EPIC array, 187 patients), producing a
dose–response gradient across critical-illness severity.

**Conclusion:** the signature separates critically ill patients from healthy
individuals, not ARDS from other critical illness. Whole-blood epigenome-wide studies
in acute/critical care should use ICU-matched comparators and standard leukocyte
composition adjustment.

## Repository layout

```
code/
  00_install.R                    one-time dependency installation (R >= 4.3, BiocManager)
  01_download.R                   GEO download + beta/phenotype matrices (base R only, no GEOquery)
  02_ewas.R                       limma EWAS, 3 contrasts, signature AUC + DeLong
  03_deconvolution.R              EpiDISH RPC (centDHSbloodDMC) cell proportions + group tests
  04_external_validation.R        GSE199591 (COVID-19, EPIC) external validation
  05_figures_nature.R             Nature-style figures (Arial, 600 dpi, Okabe-Ito palette)
  06_delta_ci_auc_equiv.R     unadjusted delta-beta 95% CIs + AUC-scale equivalence tests
  07_tost_equivalence.R           two one-sided tests (TOST) for the ARDS-vs-ICU contrast
  08_table3_recompute.R           recompute Table 3 (group means, delta-beta, AUC) from the beta matrix
  09_auc_recompute.R              AUCs with automatic direction for all three contrasts
  10_sensitivity_neutrophil_only.R  single-covariate (neutrophil-only) sensitivity EWAS
  11_neutrophil_group_stats.R     neutrophil group statistics (means, CI, Cohen d, Cliff's delta)
results/                          small key result tables (see below)
figures/                          manuscript figures (PNG, 600 dpi)
```

## How to run

1. Install R >= 4.3, then run `code/00_install.R` once.
2. Run the pipeline in order:

```r
setwd("<repo root>")          # or set ARDS_EPI_ROOT to the repo root
source("code/01_download.R")  # downloads ~1.6 GB from GEO; needs one-time patience
source("code/02_ewas.R")
source("code/03_deconvolution.R")
source("code/02_ewas.R")      # re-run to pick up cell-adjusted models
source("code/04_external_validation.R")
source("code/05_figures_nature.R")
source("code/06_delta_ci_auc_equiv.R")
source("code/07_tost_equivalence.R")
source("code/10_sensitivity_neutrophil_only.R")
source("code/11_neutrophil_group_stats.R")
```

Scripts resolve the project root automatically (walking up from the script location);
alternatively set the environment variable `ARDS_EPI_ROOT` to the repository path.
All downstream scripts read `data/processed/*.rds` produced by `01_download.R`.

## Data availability

No primary data are redistributed. All inputs are public:

- **GSE67530** (Zhang et al. 2019): 39 ARDS + 75 non-ARDS ICU controls + 30 healthy,
  whole blood, Illumina HumanMethylation450.
- **GSE199591** (Calzari et al. 2023): 187 COVID-19 patients (123 mild / 64 severe),
  blood, Illumina MethylationEPIC.
- Reference matrix `centDHSbloodDMC.m` ships with Bioconductor package **EpiDISH**.

`results/` contains the small analysis outputs (signature statistics, DeLong tests,
cell proportions, equivalence CIs, Table 3 recomputation). The genome-wide DMP tables
(485,577 probes each) are ~57 MB per contrast and are regenerated by `02_ewas.R` /
`04_external_validation.R`.

## Key files in `results/`

| File | Content |
|---|---|
| `table3_recomputed.csv` | Table 3 recomputed from the beta matrix (self-consistent means / delta-beta / AUC) |
| `equiv_delta_ci_unadj.csv` | Unadjusted delta-beta 95% CIs for the 4 signature CpGs (all inside the ±0.05 margin) |
| `ewas_delong_*.csv` | DeLong tests: combined score vs best single CpG per contrast |
| `cell_estimates_GSE67530.csv` | EpiDISH-estimated cell fractions, 144 samples x 7 types |
| `deconv_group_tests_GSE67530.csv` | Kruskal–Wallis + pairwise Wilcoxon (BH over 18 tests) |
| `gse199591_*.csv` | External-validation statistics |

## Environment

- R 4.4.2; limma (Bioconductor), EpiDISH, pROC, ggplot2/ggrepel, data.table, tidyr.
- Analyses are deterministic; external-validation scripts set a seed (42).
